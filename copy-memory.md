# Copy memory — the anti-repetition ledger for VOICE

`design-memory.md` stops two prospects from *looking* alike. This file stops them
from *sounding* alike, which is the failure that actually reaches a client: two
businesses in the same county, both handed a site whose hero is built from the
same construction.

It already happened. `cedar-grove-transmission` shipped **"Fair. Honest. Since
1961."** and `john-sessa-cpa` shipped **"Straight answers. Clean books. Since
1983."** — the same three-fragment-plus-founding-year hero, twice, in the same
portfolio. Both are good lines. That is the problem: a good construction is
exactly the one a writer reaches for again.

## How to use it

**Planner** — read the CONSTRUCTION column before you write the hero direction
(`trade-copy/references/voice-spec.md` → "Hero uniqueness"). A construction on
this list is spent. You may use the shape once more only if you say in
`website-plan.md` why this business needs it and the last user does not.

**Critic** — append a row at sign-off, in the same pass that appends to
`design-memory.md`. Quote the hero verbatim; a paraphrase makes the ledger
useless for the next planner.

Per **Lessons flow forward** (`CLAUDE.md`): rows recorded here are history, not a
fix list. Nothing below gets rewritten because it appears twice — the duplicate
is why the ledger exists, and the next build is where it pays off.

## Constructions that are now spent

Do not reach for these without a stated reason:

1. **Three fragments + "Since YYYY."** — used twice (cedar-grove, john-sessa).
2. **Negated pair** ("No X too small. No Y too big.") — law-office, and the
   banlist bans its closest cousin outright.
3. **Second-person aspiration** ("Your dream…") — duran-and-son, and it is the
   construction most likely to arrive with a motif word attached.

## What belongs in a row

Verbatim hero, the *shape* named in three or four words, and the register tier.
Not the whole voice spec — that lives in `prospects/<slug>/voice-spec.md`. This
file answers one question fast: **has a planner already used this move?**
